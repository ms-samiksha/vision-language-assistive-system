Build a complete Python Flask web application ONLY (NO React, NO Node.js, NO Vite) for my project:

Project Name: "See & Tell"
Tagline: A real-time vision–language assistive system for visually impaired users.

TECH STACK:
- Backend: Python Flask
- Frontend: HTML (Jinja templates) + CSS + JavaScript
- Storage: Local JSON files (NO database)
- Text-to-speech: Browser SpeechSynthesis API (client-side)

MAIN GOAL:
Create a user-centric web app with login/signup and personalized accessibility modes (Fully Blind / Low Vision / Standard).
The app should display live captions (dummy captions for now), show status indicator lights, store short-term object memory, and allow users to query misplaced objects.

--------------------------------------------
PAGES / ROUTES
--------------------------------------------

1) Landing Page
Route: GET /
Show:
- Project name "See & Tell"
- Short description
- Buttons: "Login" and "Sign Up"
- A small feature list (live captions, object memory, audio feedback)

2) Sign Up
Route: GET /signup and POST /signup
Fields:
- username (unique)
- password (store as hashed password using werkzeug.security)
- vision_assistance_level (dropdown):
    * Fully Blind (Voice-first)
    * Low Vision (High contrast + Large text)
    * Standard
- auto_speak (checkbox default ON for Fully Blind)
- speech_rate (range slider 140-190 default 165)
- important_objects (multi-select or comma separated):
    phone, keys, wallet, glasses, bottle, bag
Store user details in data/users.json

3) Login
Route: GET /login and POST /login
- Authenticate user from users.json
- Create session login
- Redirect to /dashboard

4) Dashboard (Main App)
Route: GET /dashboard
Show:
- A top navbar with links: Dashboard, Memory, Find, Settings, Logout
- A status indicator light:
    Green = LIVE
    Yellow = INIT or SLOW
    Red = ERROR
- Live Caption card with:
    caption text
    objects tags
    actions tags
    last updated time
- Buttons:
    "Refresh Caption"
    "Read Aloud"
    "Add to Memory"
- If user mode is Fully Blind:
    Auto speak caption whenever it updates
    UI should be minimal and have extra-large buttons

5) Memory Page
Route: GET /memory
Show a table:
- Object name
- Last seen description
- Timestamp
- User who saved it
Include a "Clear Memory" button

6) Find Object Page
Route: GET /find and POST /find
- Input: object name (example: "keys")
- Show response:
  "Your keys were last seen on the table at 10:45 AM."
If object not found:
  "Sorry, I have not seen that object recently."

7) Settings Page
Route: GET /settings and POST /settings
Allow user to update:
- vision_assistance_level
- auto_speak
- speech_rate
- important_objects
Save changes to users.json

8) Logout
Route: GET /logout
- Clear session and redirect to /

--------------------------------------------
API ENDPOINTS (FOR LIVE UPDATES)
--------------------------------------------

Create these API endpoints returning JSON:

1) GET /api/caption
Return:
{
  "status": "LIVE",
  "caption": "A person holding a red mug in a bright kitchen.",
  "objects": ["person", "mug", "kitchen"],
  "actions": ["holding"],
  "updated_at": "10:45 AM"
}

For now use dummy rotating captions (list of 6-8 captions) and rotate one every few seconds.
Also compute status:
- INIT if app just started
- LIVE if caption is available
- SLOW if last update > 5 seconds
- ERROR if something fails

2) GET /api/memory
Return memory entries from data/memory.json

3) POST /api/memory/add
Request JSON:
{
  "object": "keys",
  "description": "Keys on the table near a laptop",
  "timestamp": "10:45 AM"
}
Store this entry in memory.json

4) POST /api/memory/clear
Clears memory.json for the logged in user

--------------------------------------------
FRONTEND JAVASCRIPT BEHAVIOR
--------------------------------------------

In static/app.js implement:
- Poll /api/caption every 2 seconds
- Update caption text, tags, and status light dynamically
- If auto_speak is enabled, use SpeechSynthesis to speak caption automatically
- Implement "Read Aloud" button using SpeechSynthesis
- Make speech rate use the user’s saved speech_rate
